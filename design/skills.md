# design/ — skills.md

## Purpose
Brand tokens and voice for Tell. `tokens.json` is generated by `build_tokens.py`; never hand-edit the JSON.

## Brand personality
Calm, forensic, on your side. Like a good bouncer: unbothered, specific, never dramatic. We show evidence; we don't shout "SCAM!!!".

## Voice rules
- Verdict copy is one line, present tense, evidence second: "Likely synthetic — no breath events in 42 s."
- Never say: "100% safe", "guaranteed", "illegal call", "detected a criminal", "AI-proof". Never use fear words ("danger", "attack") in the UI.
- Below 0.6 confidence the headline is "Unsure" and the advice is the same for everyone: hang up, call back on a number you already have.
- "AI" is not an insult. A disclosed AI caller gets a neutral amber badge and the copy "AI — identified itself".

## Palette (from tokens.json)
- Primary `signal` (teal) — actions, the "bytes leaving device: 0" meter.
- Status colors are text-safe on surface in both themes (all ≥ 4.5:1, see `tokens.contrast`):
  - human → green, ai_disclosed → amber, ai_undisclosed → orange, scam → red, unsure → slate.
- Dark theme is the default for the demo (hackathon stage); light must still pass.

## Type
Display: Bricolage Grotesque. Body: IBM Plex Sans. Mono (tells, byte counter, signatures): IBM Plex Mono. Load from Google Fonts only; fall back to system.

## Rules
- Any new text/surface pair → add it to `pairs` in `build_tokens.py` and re-run. Small text must be ≥ 4.5:1.
- Status is never color-only: every status badge also carries a label and an icon/glyph.
- Mobile-first: 16 px gutters, no horizontal scroll at 380 px.

## Validation
```
python3 design/build_tokens.py   # exits 1 on any contrast failure
python3 -c "import json;json.load(open('design/tokens.json'))"
```
