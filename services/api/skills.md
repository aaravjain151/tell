# services/api — skills.md (backend domain; also owns tools/redteam)

## Purpose
`POST /analyze` turns audio and/or a transcript into a signed verdict with evidence. Everything runs locally; caller audio is never written or sent.

## Layout

## Data model
`Tell(name, family ∈ acoustic|script|intent, score 0..1, weight, evidence, applicable)` →
`Verdict(tier, p_ai, p_scam, confidence, disclosed_ai, headline, advice, tells[], thresholds_version, egress, signature, cost, reasons[], model_notes[], transcript)`.
`reasons` (list[str], 1-4): fixed sentences from `reasons.py`, built from fired deterministic tells only; the Simple view should show these instead of its own client-side map. `model_notes` (list[str], 0-3): sanitised sentences from the local LLM, DISPLAY ONLY, label them as the model's words; never feed them into a tell, tier, disclosure flag or TTS (`/speak` only says `scorer.COPY`). Both are in `/analyze` JSON; `reasons` is not in the signature payload.
Acoustic/script scores point toward AI; intent scores toward scam. `applicable=False` tells are shown but excluded from fusion.

## Rules
- Models interpret, code decides: an LLM may only add `Tell`s; it never sets the tier.
- New signal = new function returning a `Tell` with a human-readable `evidence`, a weight in `thresholds.py`, a unit test, and a line in this file.
- Any acoustic signal must say what it does on phone-band audio (`ctx["band_limited"]`). Prefer behavioral cues (timing, breath, pitch wander) over codec artifacts.
- Short input → `applicable=False`, never a guess. Clip < 4 s skips acoustics; breath needs ≥ 5 s; transcript < 25 words skips disfluency.
- Disclosure wins: a caller that says it's AI is `ai_disclosed` unless scam cues fire.
- Changing `thresholds.py`: bump `THRESHOLDS_VERSION`, run `make eval`, note the before/after in the commit body.
- Network and process use is policed two ways. Static: `tests/test_import_scan.py` AST-scans EVERY `.py` under `tell/` (no file list) for network libs, `subprocess`, `os.system/popen/exec*/spawn*`, `importlib.import_module`/`__import__`, `exec/eval`, and checks it against an exact `ALLOWLIST` (localhost.py, llm.py, speak.py, audio.py). Runtime: `tests/test_network_guard.py` runs the whole pipeline and API with every non-loopback socket call recorded and refused. A new file or new banned use must fail the scan until a reviewer adds it, with a reason, to the allowlist.
- Gradium credits: never call TTS in tests; `make_calls.py` caps at `--max 20` clips per run.
- Settings (D-013): read every `TELL_*` setting through `tell/env.py` (`_env.get("TELL_X", default)`), never `os.environ` directly. It falls back to the pre-rename `DOUBLESPEAK_X`; `tests/test_env.py` fails if any other module spells `DOUBLESPEAK_`. Tests set `TELL_*`; `tests/conftest.py` moves stray `DOUBLESPEAK_*` vars from the shell to `TELL_*` before tests run.
- `services/api/doublespeak/` is a deprecated one-file alias of `tell` (same module objects; `uvicorn doublespeak.main:app` still works). Never add code there; new code imports `tell`.

## Streaming contract (`stream.py`, D-011 PROPOSED)
1. `POST /session` (Origin must be an allowed UI origin; 429 when 2 sessions exist) -> `{session_id, token, ws_path:"/ws/stream", params}`. Token: random 256-bit, single use, expires in 60 s, never in a URL.
2. WebSocket FIRST message within 5 s: `{"type":"hello","token":...,"sample_rate":16000,"format":"pcm_s16le","side":"far|near|mix"}`. Audio/anything else first, or an unknown/reused/expired token, gets `{"type":"error","code":"hello_required"|"auth_failed"}` and a close. Host/Origin are re-checked on the handshake (the HTTP middleware does not see websocket scopes).
3. Server -> `{"type":"ready"}`. Client then sends binary PCM16 LE mono 16 kHz frames (even length, <= 128 KiB) and may send text `{"type":"ping"}` (-> `pong`), `{"type":"stop"}`, `{"type":"kill"}`. Any message is a heartbeat; silence for 15 s ends the session.
4. Every hop (3 s of NEW audio, audio clock) with no job in flight, `pipeline.analyze(last 10 s as in-memory WAV, ephemeral=True)` runs in the shared worker thread and pushes the RAW per-tick verdict (no smoothing, no alert logic; the stabiliser is another branch):
   `{"type":"verdict","seq","t","window":[t0,t1],"tier","p_ai","p_scam","confidence","headline","degraded":[non-applicable tell names],"lag_s","side","confidence_capped","dropped_ms"}`.
   Also `{"type":"warn","code":"lagging"|"overloaded"}` (throttled to one per code per 5 s), `{"type":"final","ticks":n,"reason":"stop|kill|max_length|deleted|panic"}`, `{"type":"error","code":...}`.
5. Backpressure: one job in flight per session; ticks that come due meanwhile are counted (`skipped_ticks`), the next window covers the newest audio, and the audio nobody analysed is dropped oldest-first and added to `dropped_ms`. A finished job immediately catches up.
6. Wipe on: stop, kill, disconnect, heartbeat timeout, 2 h max length, error close, `DELETE /session/{id}`, `POST /panic` (all sessions + pending tokens). A result that finishes after a wipe is discarded. GRACEFUL ends (stop, clean close 1000/1001, max length) first run `Session.finish`: the in-flight tick lands, then ONE analysis of the last window if >= 2 s of new non-silent audio follows the last scored window; sent as `verdict` + `"tail": true` before `final` (`final.tail` = scored|covered|no_new_audio|silence|timeout|failed|closed) and before SSE `ended`. Bounded by `params.final_flush_s` (`TELL_STREAM_FINAL_S`, 6 s, capped by `TELL_ANALYZE_TIMEOUT_S`). Kill/panic/DELETE/heartbeat/errors: immediate wipe, no extra analysis. Tests: `test_stream_tail.py`.
7. `side=mix` (both speakers in one signal) caps DISPLAYED confidence at 0.6 (`session.MIX_CONF_CAP`) and sets `confidence_capped`; tier/p_ai/p_scam are untouched, scorer.py is not edited.
8. Env (read per call): `TELL_STREAM_{WINDOW_S,HOP_S,RING_S (cap 120),HEARTBEAT_S,HELLO_TIMEOUT_S,TOKEN_TTL_S,MAX_SESSION_S}`.
9. Privacy: audio lives only in the ring (zeroed on close) and the one window copy the worker holds until its analysis returns; `pipeline.analyze(..., ephemeral=True)` ignores `TELL_DEBUG_SAVE` and skips the opt-in history file. Tests: `test_stream.py::test_no_file_is_created_during_a_session`, `::test_debug_save_is_ignored_by_real_pipeline`.
